# Terminal Arrow

Terminal Arrow is a powerful, modern, and feature-rich terminal emulator and SSH client built with Kotlin. It is designed for power users, system administrators, and developers who need a robust, secure, and syncable terminal experience across all their devices.

## Features

This section outlines the planned features for Terminal Arrow and their current implementation status.

### Synchronization & Cloud Vault
*   [ ] **Encrypted Cloud Vault:** Sync hosts, servers, snippets, and settings securely via an encrypted cloud vault.
*   [ ] **Unlimited Device Sync:** Synchronize across an unlimited number of devices.
*   [ ] **Shared Vault / Team Collaboration:** Share specific vaults or configurations with team members securely.

### Connection Protocols
*   [ ] **SSH:** Full SSH support.
*   [ ] **SFTP:** Built-in SFTP file manager for seamless file transfers.
*   [ ] **Mosh:** Support for Mobile Shell (Mosh) for robust connections over roaming networks.
*   [ ] **Telnet:** Legacy Telnet support.
*   [ ] **Serial Cable Connection:** Direct serial connection to hardware and network devices.

### Advanced Networking
*   [ ] **Port Forwarding:** Local, remote, and dynamic port forwarding.
*   [ ] **Proxy & Jump Host/Bastion Support:** Connect through complex network topologies using proxy servers or jump hosts.
*   [ ] **Cloud Integrations:** Native integration with AWS and DigitalOcean for quick access to instances.

### Terminal & UI/UX
*   [ ] **Multi-Tab Terminal & Split View:** Manage multiple sessions simultaneously with tabs and split panes.
*   [ ] **Theme & Font Customization:** Extensive customization options for terminal themes, colors, and fonts to suit your workflow.
*   [ ] **Custom Keyboard Toolbar (Android):** A specialized keyboard toolbar on Android providing quick access to common terminal keys (Ctrl, Alt, Esc, Arrow keys, etc.).
*   [ ] **Modern UI/UX:** A clean, intuitive, and responsive user interface designed for productivity.

### Productivity Tools
*   [ ] **Snippets / Saved Commands:** Save and quickly execute frequently used commands.
*   [ ] **IDE-like Autocomplete:** Intelligent command autocomplete and suggestions to speed up your workflow.
*   [ ] **Command History:** Persistent command history synced across devices.
*   [ ] **Custom Environment Variables:** Define and manage custom environment variables per session or globally.

### Security & Key Management
*   [ ] **SSH Key Management:** Generate, import, and manage SSH keys securely within the app.
*   [ ] **SSH Agent Forwarding:** Securely forward your SSH agent to remote hosts.
*   [ ] **FIDO2 Hardware Key Support:** Support for YubiKey and other FIDO2 hardware security keys.
*   [ ] **Biometric Lock:** Secure the app with Fingerprint or Face ID.
*   [ ] **2FA Account Protection:** Two-factor authentication to protect your Terminal Arrow account and synced data.
